# 问题排查

用于 SupportFlow 桌面端与企微通道相关故障的定位。

## 适用场景

- 连接失败、消息不同步、工具调用报错
- 需要结合日志与配置判断根因

## 工作流

1. 明确现象、期望行为、最近变更
2. 查看 `agent_read_logs` 或工作区日志文件
3. 检查 `config.json`、渠道状态、许可证（若涉及连接）
4. 提出**最小修复**方案，避免无关重构
5. 给出可执行的验证步骤（重启、重连、单步复现）

## 输出格式

- **现象**
- **可能原因**（按概率排序）
- **建议操作**
- **如何确认已修复**
