# 回复起草

为企微对话、工单备注生成可直接发送或略作修改的回复草稿。

## 适用场景

- 需要快速给出首版回复
- 同一问题需要「简短版 / 详细版」

## 工作流

1. 归纳客户问题与已提供信息
2. 检索知识库补全事实，不编造政策
3. 默认输出一版**可直接发送**的简体中文
4. 可选附加「简短版」供一线快速回复

## 格式要求

- 首句回应客户关切
- 正文条理清晰；必要时用编号步骤
- 结尾可留开放式跟进（如「如需我继续协助…」）
